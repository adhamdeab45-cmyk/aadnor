ADNOR V230 — إيداع USDT بموافقة الأدمن
=====================================

الموقع:
- app.html: إزالة نموذج الإيداع الآلي وQR/TXID. اختيار USD ثم USDT، إدخال المبلغ، وإرسال طلب يدوي للأدمن.
- app.html: زر موافقة/رفض الإيداع في لوحة الإدارة يستخدم API الخادم، ولا يعدّل الرصيد مباشرة من المتصفح.
- database.rules.json: صلاحية تعديل طرق الدفع للأدمن فقط.
- service-worker.js وversion.json: إصدار الموقع 2.3.0 وكاش V230.

الخادم:
- src/server.js: طلب الإيداع اليدوي لا يحتاج رفع إيصال؛ يبقى Pending إلى أن يوافق الأدمن من API.
- src/server.js: مسارات الإيداع التلقائي القديمة موقوفة، والإضافة إلى الرصيد تتم بعد موافقة الأدمن فقط.
- package.json وpackage-lock.json: API 1.6.6 وروابط npm عامة.
